# design/

Mockups go here. They are the source of truth for what the game should look like — never
evidence of what it does look like. Rendered output is checked by a human on a physical device.

Current contents:
- `Do Not Blink.html` — the design reference document.
- `screens/` — per-screen mockups, numbered in flow order:
  `01_SPLASH`, `02_HOME`, `03_Playing_Hold`, `04_Playing_PerfectRelease`,
  `05_Fail_BannerSurface`, `06_Continue_Offer`, `07_INTERSTITAL_Moment`, `08_TITLES`,
  `09_Settigns`, `Blinked`, `12_test`.
